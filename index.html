Overview

Six years of forecasted risk, six ways to slice it

The dashboard covers spatial analysis, ward-level rankings, temporal trends, and year-over-year change detection — each as its own view, so a user can move from "what does the whole city look like right now" to "which specific blocks changed the most between 2025 and 2026" without leaving the tool.

Capabilities

What the dashboard actually does

Spatial analysis

Grid-level risk map

Leaflet choropleth of every grid cell, colored on the risk scale, filterable by ward and year, with an animated slider to scrub through the forecast horizon.

Year-wise changes

Period-over-period deltas

Every consecutive year pair (2023→24, 24→25, …) is scored into five change categories from major decrease to major increase, mapped and ranked by magnitude.

Ward analysis

Ranking & velocity

Wards ranked by high-risk share, average score, or very-high-risk count, plus a velocity view showing which wards are accelerating fastest across the full horizon.

Temporal trends

City & ward trajectories

Loess-smoothed trend lines with optional change-point highlighting, comparable across the five highest-risk wards at once.

Data explorer

Filterable table + export

Full underlying dataset — current risk or year-wise changes — filterable by year, ward, and risk level, downloadable as CSV.

Confidence tracking

Model uncertainty, surfaced

Every prediction carries a confidence score, aggregated per ward and year so low-confidence forecasts aren't presented as certainty.

Pipeline

From raw grid data to a live map

01

Ingest & validate spatial + forecast data

Loads grid-level forecast scores and GeoJSON polygons, coercing IDs to consistent types across sources so spatial joins don't silently drop rows.

sfreadrdplyr
02

Assign wards & build boundaries

Joins each grid cell to its ward using real ward-assignment data, with a coordinate-based fallback so the app degrades gracefully if that file is missing.

st_polygonpurrr
03

Compute year-over-year change

Pivots each consecutive year pair, calculates the score delta per grid cell, and buckets it into five change categories by magnitude.

tidyr::pivot_widerpurrr::map_dfr
04

Aggregate ward & city statistics

Rolls grid-level data up to yearly city-wide stats and yearly ward-level stats — high-risk share, average score, confidence, very-high-risk counts.

05

Serve it as a reactive dashboard

Six tabs, all built on reactive filters, so every map, chart, and table updates together as the user changes year, ward, or metric.

shinydashboardleafletplotlyDT
